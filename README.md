# 🩸 Sanguinary Class

**Sanguinary** is a custom class mod for **Mewgenics**, focused on blood manipulation, self-damage, Bleed, and recovering health through aggressive play.

> Sacrifice your own blood. Spill theirs. Take it back.

## Features

- 🩸 Custom Sanguinary class (Not fully implemented)
- 🏷️ Custom class collar (Not fully implemented)
- 🩸 Basic attacks inflict **Bleed**
- ⚔️ Blood-focused abilities and passives
- 🇧🇷  Brazilian Portuguese localization (Not fully implemented)

## Gameplay

Sanguinary is built around a high-risk, high-reward playstyle:

**Inflict Bleed → Sacrifice HP → Deal massive damage → Recover health from bleeding enemies → Repeat.**

Managing your own health is a core part of playing the class.
